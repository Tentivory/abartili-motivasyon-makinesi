# 🚀 Abartılı Motivasyon Makinesi

**Dikkat!** Bu depo dünyanın en ciddiye alınması gereken motivasyon aracıdır. Hayatınızı tamamen değiştirecek. Veya hiçbir şey değiştirmeyecek. Ama en azından gülümseyeceksiniz.

## Ne Yapar?

Bu devrim niteliğindeki yazılım, her çalıştırıldığında size özel, kişiselleştirilmiş, bilimsel olarak kanıtlanmış (kanıtlanmamış) motivasyon cümleleri üretir. 

- ✅ Gerçekten çalışır
- ✅ Hiçbir şey yapmaz ama yapar gibi görünür
- ✅ Kahve içmenizi sağlamaz ama kahve içerken çalıştırabilirsiniz
- ✅ 15 farklı abartılı cümle içerir
- ✅ Rastgele seçer çünkü algoritma öyle istiyor

## Nasıl Kullanılır?

1. Bu depoyu klonla (veya sadece dosyayı indir)
2. Terminal aç
3. Şunu yaz:
   ```bash
   python motivasyon.py
   ```
4. Hayatının değişmesini bekle
5. Değişmezse tekrar çalıştır
